How to use IssueMatcher

1
Connect with your Jira credentials

Sign in with your Jira username and password (Basic Auth) or switch to a Personal Access Token (PAT). Credentials live only in backend server memory and are wiped when you click Disconnect or stop the server.

2
Describe the issue or paste a ticket key

Enter a natural-language description, a draft Jira summary, or an existing ticket key (e.g. TMRW-746582). Press Ctrl + Enter to run the search.

3
Narrow scope when helpful

Use the Program/Project and Issue Type dropdowns to focus on a specific team or ticket category. Keep Include resolved issues enabled to catch previously solved work.

4
Review hybrid Keyword + AI scores

Each match shows a Keyword Match score, an AI Relevance score, and an Overall Match score (High ≥ 70%, Medium 40–69%, Low < 40%), along with shared concepts and important scope differences.
