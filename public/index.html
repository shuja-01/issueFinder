User Guide & Keyboard Shortcuts

01 Connect securely

Sign in using your Jira username & password (Basic Auth) or a Personal Access Token. Secrets stay in local server memory only.

02 Search smartly

Describe an issue, paste a Jira summary, or enter a ticket key (e.g. TMRW-637722). Use the searchable Program/Project filter to narrow across 100+ projects instantly.

03 Inspect side-by-side

Click any result to read its full description, AI shared concepts & differences, linked tickets, and recent comments without leaving IssueMatcher.

04 Pivot & Export

Use Find Similar on any ticket to pivot search, or export your duplicate check as CSV or a Teams-ready Markdown summary.
